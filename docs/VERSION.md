## Versioning Rules

The system shall use the `00.00` version format to remain consistent with the SRS, SDD, and SPMP documents.

- **Major Version (`XX.00`):** Increment the major version for significant system revisions, major architectural changes, or changes that substantially affect the overall system. Reset the minor version to `00`.
- **Minor Version (`00.XX`):** Increment the minor version for new features, bug fixes, enhancements, and other improvements that do not warrant a major version change.

### Examples

- `01.00` — Initial system version.
- `01.01` — Bug fixes and minor improvements.
- `01.02` — Additional features and enhancements.
- `02.00` — Major system revision.

These examples are guidelines. Version changes must be based on the scope and impact of the changes, not simply the number of files modified.
